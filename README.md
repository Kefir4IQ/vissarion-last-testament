# Последний Завет · Слово Виссариона

**Учебный корпус о душе, Боге, смысле жизни и духовном развитии.** Путеводитель для читателя и база знаний для ИИ-агента, который отвечает с опорой на конкретные книги и страницы.

В учебный корпус входят семь текстов вместе с предоставленными русскими PDF в [texts/ru](texts/ru/README.md). Полные наименования, сведения об изданиях и правила цитирования приведены в [реестре источников](docs/sources.md). Проект посвящён прочтению этих текстов изнутри учения. «Повествование от Вадима» и «Время Грозы» отнесены к отдельному проекту о хронологии Свершения.

[Английские переводы на Booksie](docs/english-sources.md) включены как каталог внешних публикаций с указанием переводчика, без копирования их полного текста.

[English source library](texts/en/README.md) maps all seven Russian books to available English publications and marks missing or incomplete translations.

## Для ИИ-агентов

- [AGENTS.md](AGENTS.md) задаёт порядок работы, пределы корпуса и формат ссылок.
- [corpus.json](knowledge/corpus.json) содержит реестр книг, карточки фрагментов, тематический указатель, словарь, граф и ответы на типовые вопросы.
- [Схема JSON](knowledge/corpus.schema.json) описывает поля и типы данных.
- [Подключение к агенту и RAG](docs/integration.md) объясняет импорт, поиск, проверку ответа и работу с редакциями.
- [Универсальная инструкция для агента](AGENTS.universal.md) готова к вставке в настройки англоязычного или многоязычного агента. [Описание адаптера](docs/multilingual.md) и [дополнение к AGENTS.md](AGENTS.multilingual.md) объясняют поиск по русскому оригиналу.

Базовый поиск по указателю работает локально в Python 3.10 и новее без сторонних пакетов и API-ключей. Для поиска по страницам оригинальных PDF дополнительно нужен PyMuPDF.

~~~sh
python3 tools/corpus.py verify
python3 tools/verify_sources.py
python3 tools/corpus.py search "Что такое рождение Свыше?"
python3 tools/corpus.py concept "Благодать" --json
~~~

Для иноязычного запроса агент формирует русские варианты поиска и передаёт их программе `tools/multilingual_adapter.py`. Программа автоматически ищет также по страницам семи PDF в `texts/ru`. Ответ агент переводит на язык читателя, сохраняя русское название книги и номера страниц. При необходимости `pdf_dir` укажет другую папку с оригиналами. [Пример вызова](docs/multilingual.md#tool-contract).

Результаты поиска ведут к фрагментам. Для дословного цитирования откройте указанное место в соответствующем издании. [Индекс фрагментов](docs/evidence.md).

## Публикация и правки

[Материалы для публикации](docs/publishing.md) содержат название, описание, темы поиска и порядок переноса на GitHub и другие площадки. [Правила редакторской работы](docs/method.md) помогают добавлять понятия, сопоставления и проверяемые ссылки.

В комплекте находятся полные PDF из предоставленных копий. Инициатор проекта сообщает, что согласовывал распространение книг с Учителем; [происхождение и статус прав](docs/rights.md) описаны отдельно. Лицензия Unlicense для программного кода в GitHub-репозитории не распространяется на исходные книги и переводы.
