# Русские оригиналы

В этой папке семь предоставленных пользователем PDF, которые использованы при составлении учебного корпуса. Файлы сохранены под исходными именами. Список книг и прямые ссылки на каждый файл находятся в [реестре источников](../../docs/sources.md). Контрольные суммы SHA-256 и размеры записаны в [manifest.json](manifest.json).

Из корня репозитория выполните:

```sh
python3 tools/verify_sources.py
python3 tools/corpus.py verify
```

Для поиска по русскому тексту страниц используйте [языковой адаптер](../../docs/multilingual.md). Он автоматически найдёт эту папку при запуске внутри проекта. Для прямой цитаты проверьте видимый текст в PDF: извлечение строк из двух длинных файлов требует исправления кодировки и может менять порядок колонок.
