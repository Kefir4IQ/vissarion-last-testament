# Английские переводы: профиль promisedword на Booksie

**Статус:** внешние публикации для сопоставления с русским оригиналом. По сообщению инициатора, переводы выполнены последователем Виссариона по поручению Учителя; инициатор подтверждает согласие переводчика на их распространение. На странице Booksie указан псевдоним `promisedword`.

**Профиль:** [promisedword Portfolio](https://www.booksie.com/portfolio-view/promisedword-265927). На странице профиля перечислены семь работ, пять из которых по заголовку относятся к пяти книгам данного корпуса:

Отдельный [раздел английской библиотеки](../texts/en/README.md) содержит соответствия для всех семи книг и [машинный каталог](../texts/en/catalog.json). Четыре из пяти публикаций помечены на Booksie как `Finished`; «Pivotal Time» — как `In progress`. Статус площадки сам по себе не подтверждает полноту совпадения с конкретным русским PDF.

Остальные две работы профиля имеют другие заголовки и не являются подтверждёнными переводами «Книги Основ» и «Книги Обращений». Названия в таблице позволяют найти соответствующие публикации, но точное соответствие абзац к абзацу не установлено.

## Правило для англоязычного агента

Ищи и обосновывай ответ по [русским PDF](sources.md) и русским карточкам корпуса. Используй страницы Booksie как вспомогательный англоязычный словарь и как ссылки для самостоятельного чтения. При расхождении выбирай формулировку, подтверждённую русским местом; английские цитаты атрибутируй переводчику и проверяй на самой странице. Не подставляй английскую пагинацию вместо координат русского PDF.

## Условия дальнейшего размещения

Это каталог ссылок, полный текст перевода сюда пока не копируется. Инициатор сообщил о согласии переводчика, однако [условия Booksie](https://www.booksie.com/register/terms-services) отдельно ограничивают копирование материалов с площадки. Для размещения полного перевода предпочтителен исходный файл, предоставленный самим переводчиком или из другого разрешённого им источника. Состояние прав на русские оригиналы описано [отдельно](rights.md).
