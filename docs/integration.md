# Как подключить корпус к ИИ-агенту

## Минимальный вариант

Дайте агенту [AGENTS.md](../AGENTS.md), [реестр источников](sources.md), [corpus.json](../knowledge/corpus.json) и [семь оригинальных PDF](../texts/ru/README.md). `tools/corpus.py` ищет по аннотированному указателю; `tools/multilingual_adapter.py` дополнительно ищет по страницам оригиналов. Выдача показывает кандидатов для сверки. Для дословной цитаты агент должен открыть соответствующую страницу PDF.

Для англоязычного и любого другого языка добавьте [AGENTS.universal.md](../AGENTS.universal.md) и [языковой адаптер](multilingual.md). Агент сначала переводит вопрос в русские запросы, затем ищет по страницам PDF из `texts/ru` и указателю и отвечает на языке пользователя по найденным местам. `pdf_dir` нужен лишь для другой папки с исходниками.

```sh
python3 tools/corpus.py verify
python3 tools/corpus.py search "Что такое душа и зачем трудиться?" --json
python3 tools/corpus.py search "Благодать" --book foundations --limit 4 --json
python3 tools/corpus.py concept "Благодать" --json
```

Поиск выдаёт `status: candidates` и `results` или `status: no_match`. Наличие кандидата указывает на тематическое совпадение, после которого агент должен проверить подходящую карточку и оригинальное место. `kind: navigation` означает ориентир по главе; `kind: paraphrase` содержит учебный пересказ. Поле `citation` формируется из книги, главы, диапазона PDF страниц и, где она есть, печатной пагинации.

## Если используется RAG

Создайте один индексный документ на каждый элемент `evidence` и сохраняйте в метаданных `id`, `kind`, `source.book`, `source.chapter`, `source.locator`, `source.pdf_pages`, `title`, `summary`. Для первоначального ответа предпочитайте записи `paraphrase`; записи `navigation` помогают обнаружить нужную главу. Ключи словаря `concepts` и графа `relations` служат маршрутом к карточкам по полю `evidence`. Запись связи с `kind: Сопоставление` требует именно такой оговорки в ответе. Точные цитаты получайте только из сверенного текста PDF.

Минимальный алгоритм:

1. Разобрать вопрос, найти вероятные понятия и запустить поиск по смысловым словам.
2. Отобрать 1–4 карточки, открыть их `source`; для сильного тезиса сверить первичный фрагмент.
3. Составить ответ, приписав тезисы конкретным книгам. Редакторские связи назвать сопоставлением.
4. Вывести название книги, главу/пункт и страницы PDF. Для цитирования выбрать совпадающую редакцию.
5. При слабой или отсутствующей опоре вернуть частичный ответ или явное отсутствие ответа в данном корпусе.

### Контракт ответа агента

```json
{
  "status": "supported | partial | no_finding",
  "answer": "Краткий ответ с указанием, что именно говорят книги",
  "evidence_ids": ["E08", "E65"],
  "citations": ["Книга Основ, гл. 3, § 25–49, PDF с. 5–6"],
  "interpretation": "Если есть редакторское сопоставление, обозначить его здесь",
  "limitations": "Что не установлено приведёнными местами"
}
```

У полей `status` и `citations` нет функции автоматической проверки истинности: проверка состоит в сопоставлении ответа с первичным местом. Для вопроса вне семи книг не подставляйте подходящие по звучанию карточки. Особенно важно не выдавать религиозное представление за проверенный факт о здоровье, конкретном человеке или истории.

## Обновление

Существующие `id` карточек, понятий и связей сохраняются между редакциями. При добавлении издания укажите его в [реестре](sources.md), проверьте изменённую пагинацию, обновите ссылающиеся карточки и запустите `python3 tools/corpus.py verify`. [Правила работы с источниками](method.md) описывают степень надёжности разных видов записей.
