# Карточка и порядок публикации

**Название:** Последний Завет · учебный корпус семи книг Слова Виссариона.

**Краткое описание:** Проверяемый путеводитель по семи книгам: душа, Бог, смысл жизни, свобода выбора, любовь, молитва, труд и развитие человека. Включает учебный курс, словарь, карту связей, базу знаний и языковой адаптер для ИИ-агентов со ссылками на книги и страницы.

**Описание для каталога:** Этот проект помогает искать и изучать учение Виссариона по конкретным письменным источникам. Читатель найдёт короткое введение, самостоятельный курс из 12 занятий, путеводитель по каждой книге, словарь понятий, сопоставления и вопросы с опорой на фрагменты. Разработчик может подключить JSON-базу к агенту и требовать ссылки на главы, пункты и страницы. Два хроникальных текста, «Повествование от Вадима» и «Время Грозы», составят отдельную событийную хронологию.

**Темы поиска:** `Виссарион`, `Последний Завет`, `Книга Основ`, `душа`, `Бог`, `смысл жизни`, `духовное развитие`, `молитва`, `книга обращений`, `книжный корпус`, `база знаний`, `RAG`, `AI agents`.

## GitHub

1. Прочтите [сведения о происхождении и правах](rights.md): в них записано сообщение инициатора о согласовании распространения с Учителем и границы этого свидетельства. Unlicense относится к программному коду, а не к оригинальным книгам или английским переводам.
2. Создайте репозиторий с описанием выше и загрузите содержимое папки `posledniy-zavet` **в корень репозитория**, чтобы `README.md` открывался первым. Семь оригинальных PDF находятся в `texts/ru`.
3. Проверьте команды `python3 tools/corpus.py verify` и `python3 tools/verify_sources.py` из корня. Поиск по текстам PDF требует PyMuPDF; пример запроса дан в [инструкции для агента](integration.md).
4. Если появится другая редакция книг, укажите её в [реестре](sources.md), прежде чем переносить цитаты и номера страниц.

При загрузке через браузер выберите **содержимое** распакованной папки `posledniy-zavet`, включая `texts/ru`, а не сам ZIP-файл. Для загрузки в существующий репозиторий командной строкой:

```sh
git clone https://github.com/Kefir4IQ/vissarion-last-testament.git
cp -a posledniy-zavet/. vissarion-last-testament/
cd vissarion-last-testament
python3 tools/corpus.py verify
python3 tools/verify_sources.py
git add .
git commit -m "Publish seven-book study corpus and Russian originals"
git push origin main
```

Распакуйте ZIP до выполнения этих команд и запускайте их из каталога, содержащего папку `posledniy-zavet`. Команды сохраняют существующую историю и `LICENSE`. Отдельный файл `.gitattributes` задаёт двоичный режим для PDF. Документация GitHub описывает загрузку файлов через браузер и командную строку по ссылкам ниже.

[Создание репозитория](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository) · [Загрузка файлов](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository) · [О README](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes).

## Другие площадки

Разместите [введение](overview.md) и [курс](course.md) как читаемую точку входа. Дайте ссылку на [реестр](sources.md), чтобы читатель видел объём корпуса и правила пагинации. Для площадок с ИИ-поиском загрузите `knowledge/corpus.json` как индекс, `AGENTS.md` как правила ответа, а `AGENTS.multilingual.md`, `tools/multilingual_adapter.py` и, при наличии прав на распространение, `texts/ru/` для поиска в оригиналах. Сохраняйте адрес каждого фрагмента в ответе. Архивы событийного проекта следует публиковать отдельной подборкой, когда их источники будут изучены.
